# Stock-Movement Attribution Records

This repository is the planned release location for the annotation records
associated with the EACL 2027 Findings paper
“Evaluating Reasoning-Intensive Retrieval through Information-Seeking and
Causal Attribution in Stock Price Dynamics.”

The release will contain 500 query-level JSON records with 578 annotated
causes. The data files will be made public no later than the publication
of the paper.

The dataset files are not yet available in this repository. Please refer
to the paper for the research task and experimental results.
